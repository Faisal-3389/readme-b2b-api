Moon's Card Issuance API enables you to issue payment credentials (cards) and purchase branded gift cards for your customers.

We offer a simple REST API to:

- Issue a card
- Fetch a card and its associated information
- Add a balance to a card (if reloadable)
- Get the transaction history for a card
- Create and remove webhook endpoints that will receive notifications of events (e.g. card transactions, deposits)
- Add funds to your account via the generation of invoices
- Simulate card transactions (sandbox only)

<br />

For branded gift cards our API allows you to:

- View list of gift card products available for purchase
- Purchase a gift card
- Mark a gift card as used or unused
